# Python standards map

Use project guidance first. These references provide defaults when the project is silent.

- [PEP 8](https://peps.python.org/pep-0008/): style, layout, naming, imports, whitespace, and project-specific precedence.
- [PEP 20](https://peps.python.org/pep-0020/): explicit, simple, readable Python.
- [PEP 257](https://peps.python.org/pep-0257/): docstring conventions.
- [PEP 484](https://peps.python.org/pep-0484/) and [PEP 526](https://peps.python.org/pep-0526/): type annotation foundations.
- [PEP 585](https://peps.python.org/pep-0585/) and [PEP 604](https://peps.python.org/pep-0604/): modern generic and union syntax, subject to the resolved target.
- [Python typing specification](https://typing.python.org/en/latest/spec/): current consolidated typing authority.
- [Ruff configuration](https://docs.astral.sh/ruff/configuration/): configuration discovery, `extend`, and target-version behaviour.
